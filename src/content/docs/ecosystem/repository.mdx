Browse and install all available broadcast plugins directly from **Ember Motion Studio**. Copy the ID of a plugin below and use it in the **Catalog** section of the desktop app.

## How to Install a Plugin
1. Open **Ember Motion Studio**.
2. Go to the **Catalog** tab in the main menu.
3. Search for the plugin by name or paste its unique ID.
4. Click **Install** — the engine handles the rest and loads it into your library instantly.
